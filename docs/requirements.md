# 产品透视：目标、需求与执行清单

更新：2026-11-15

## 产品目标

制作面向产品经理和产品新手的可视化产品知识库。用户选择一个产品品类，借助真实感 3D 外观、可操作的结构目录和通俗的部件分析，理解产品由什么组成、各部分的作用及关系、软硬件如何协同，并逐步理解方案选择。

产品以**典型品类或系列**为单位，不建立品牌型号采集库；同一品类只有在使用场景或技术架构有实质差异时才拆分类型。选有代表性的方案作为研究参考，以原创或授权明确的模型表现，不声称还原某个具体型号。

## 产品原则

- 先保证产品外观真实、比例和材质可信，再展开内部；内部保留主要部件及合理堆叠、连接关系，不追求螺丝和细小线材。
- 管理者预先制作模型、部件和材质；用户在网页查看、旋转、选择显示状态，不需要自行建模或配置材质。网页实际呈现仍需使用可交互的模型与渲染，不能假定离线渲染图片可以支持任意旋转和自由组合。
- 产品外观尽量采用白色、米色或蓝色；优先暖白，部件选中使用蓝色等有对比的提示。用户需能看清浅色物体的边缘、部件与标记。
- 借鉴 KeyShot 的产品级视觉质感，实际效果必须通过网页视觉验收，不能以参数、代码或部署成功代替验收。
- 尊重素材及模型授权；不把外观稍作修改视为侵权风险已排除。准确性不足处标注为示意，不虚构具体型号内部结构。

## 执行顺序

1. 搜集多角度磁吸充电宝照片、尺寸和内部拆解/技术资料，选择可查证的典型架构，记录来源和示意假设。
2. 以参考为依据制作独立零部件的原创模型，优先完成外观轮廓、比例、接口、表面与材质；使用暖白、柔和灯光和背景对比。
3. 在建模软件中渲染检查正面、侧面、背面及倾斜视角，迭代直至看起来像实物；独立审阅并记录差距。
4. 加入合理的内部堆叠，并导出适合网页的可操作模型，验证节点、材质和授权。
5. 接入现有网站，保留已认可的旋转操作，实现目录双向联动、每个部件的显示/隐藏/透明和复位。
6. 验证右侧部件分析与技术链路，明确事实来源；补足可读性和配色。
7. 实测电脑与手机：外观、旋转、缩放、点击、透视、隐藏、展开、复位、加载失败与回归。记录测试结果、问题与是否通过；视觉目标不达标就继续迭代。
8. 完成后更新此清单的状态和证据，交付可访问页面和未解决事项；每次修改前后都对照清单，避免破坏已有功能。

## 记录规则

状态统一为：未开始 / 进行中 / 部分完成 / 已通过 / 受阻；“已通过”须记录实际测试内容与证据。后续每次执行先读取本清单，完成后更新；不把未经用户或独立审阅验证的视觉效果标成已通过。

### 硬规则：只展示当前拆解产品

工作原理的 3D 画面只呈现当前拆解产品及其组成部件，禁止加入充电器、线缆、插头、手机、手机接收线圈或任何其他外部产品、替代物与仿真模型。此规则适用于所有产品、所有步骤和动效，包括开始、切换及循环阶段。外部输入或输出从当前产品的接口、线圈等边界开始或结束，使用简洁的文字、能量粒子、箭头及信号线解释，不绘制外部实体。保留能量路径与通信、检测、控制信号的视觉区分，并按照实际工作顺序连续演示。

**验收：**逐步骤检查 3D 画面与循环切换，无外部产品、线材、接收端实体或替代图形；即便不出现外部模型，也能看懂输入、判断和输出过程。


## 工作原理命名规则

- 工作原理的场景、流程及切换项采用准确、简洁的专业术语，以当前产品为主体命名。例如移动电源使用“充电过程”和“放电过程”；需要区分输出方式时使用“有线放电”“无线放电”。
- 新增其他产品时，根据其实际工作机制选择对应的规范术语，保持同级名称结构一致，不使用“给某设备做某事”式口语化标题。

## 工作原理流程框与转换标注

- 流程节点只使用两种轮廓。普通步骤（含输入、输出、检测、转换和执行）统一使用圆角矩形。只有根据条件决定后续动作的判断步骤使用对称菱形。两种节点均沿用灰色默认态、蓝色当前态。
- 外部电源转换示意中，“交流电”、AC → DC 转换框及“直流电”使用同一绘制平面和水平中心线。输入、输出连线对齐转换框左右边的中点，输出端接入产品输入路径。旋转模型或调整窗口时仍须保持对齐。
- 转换节点只标明电能形式。具体电压如需解释，放在对应的协议协商或电压调节步骤。

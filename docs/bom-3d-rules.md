# 产品拆解：BOM 划分与规格展示规则

## 一、目标和适用范围

让用户既能理解产品由什么组成、各部件做什么，也能从采购和成本视角识别需要独立管理的物料。产品结构、3D 模型和右侧信息必须指向同一个部件。模型是理解结构的示意，不代替实物图纸或供应商 BOM。

## 二、BOM 如何划分

### 1. 先确定结构，再确定采购边界

按照「整机 → 功能组件 → 物料」组织。组件用于归类，物料是当前采购方案下可独立采购、计价或管理的最小单位。层级按实际结构确定，不必每个分支一样深。

1. 识别产品的主要组件和装配关系，列出各组件包含的实体。
2. 对每个实体判断它是否作为独立物料供应或管理：是，则单列；随其他物料一起供应，则归入该物料。
3. 同一物料中接缝、孔、印刷、纹理等只是结构或表面特征，不单列 BOM。颜色和材质不同可作为判断线索，但不单独证明一定分件。
4. 供应方式、装配边界不明时，保留为待核实或示意，不把推测当成实际 BOM；用户明确提供的划分作为当前项目的设计依据。
5. 物料数量与组合件成本不能重复累计。PCBA 可整体采购，也可以拆分 PCB 和元件；其功能拆解用于理解时，不自动计入第二套 BOM。连接器、LED、电芯与电池包同样按实际供货边界判断。

### 2. 当前产品示例

磁吸充电宝按外观与结构、电池、磁吸与无线充电、电路板归类。中框与后壳按用户确认分成两个独立项；前壳表面标识和壳体接缝属于对应壳体的细节。电芯、线圈、磁铁组件和 PCBA 分别展示；PCBA 作为一个采购物料展示，不在结构目录下重复列出 PCB、芯片及电路功能；芯片和电路的作用可在工作原理中介绍。

## 三、BOM 与 3D 交互

- 为每个物料分配稳定 ID、名称和对应的模型网格；一个物料可对应多个网格，一个网格只归属一个最具体的物料。
- 选中左侧物料时，高亮对应实体并显示其信息；点击模型时同步目录与信息。组件选择可聚合其子物料。切换选中应清除旧高亮，并保留用户已设置的展开、隐藏和视角状态。
- 爆炸图沿主要装配方向分层：独立物料分别移动，属于同一物料的表面、标识等跟随移动。保留装配关系、留出间距；收合后精确复位。充电宝的后壳、中框及前壳应分别可见。
- 对无 3D 支持或模型加载失败的环境提供明确提示。模型位置、比例和内部结构若为示意，不当成实物测绘结果。

## 四、右侧产品与规格信息怎么填

### 1. 通用原则

根据所选层级和部件类型，展示理解、比较和选型所需的核心信息。先功能，再关键规格；有依据才填数值、型号和工艺。未知数据写「未披露」或「待确认」，不把整机尺寸当成零件尺寸，也不把常见做法写成该样机的实测事实。来源、型号、版本及适用条件要能追溯；不堆叠泛化提示和与判断无关的文字。

| 选择对象 | 主要填写内容 |
| --- | --- |
| 整机 | 核心性能、容量与功率、接口、尺寸重量、兼容性等，按重要性排列 |
| 外观结构件 | 功能、材质、尺寸、工艺；涉及装配或体验的必要参数可补充 |
| 电芯 | 功能、类型及数量、型号、容量、标称电压与能量；有依据时补充尺寸和安全要求 |
| 电路板及电子器件 | 功能、型号、关键电气性能、尺寸和必要接口；按元件类型调整 |
| 磁铁、线圈等 | 功能、材料及与性能直接相关的规格；未披露的参数不编造 |

### 2. 外观结构件字段

- **功能**：一句话说明这个件的主要作用。
- **材质**：填写已知材料；未知时写未披露，表面触感不等于基材。
- **尺寸**：填写该零件本身的尺寸及单位，必要时补充公差；只有整机尺寸时不冒充部件尺寸。
- **工艺**：写实际已知成型或表面工艺。仅知道行业常见做法时，明确标记为参考；没有信息写未披露。
- 如某项确实影响理解或选型，可补充一项必要信息，不预设冗长说明。

### 3. 工艺说明交互

- 当工艺字段出现具体工艺名称时，在名称后显示信息图标；点击或键盘操作可展开一句话，解释这种工艺是如何实现的。
- 多个工艺分别对应自己的说明；说明应简洁且与工艺名称匹配。点击图标不跳转、不改变选中部件；可再次关闭。
- 工艺未披露或没有可确认的名称时，不显示无内容的图标。常见工艺的解释是通用知识，不能证明该产品实际使用了该工艺。

## 五、验收

1. 核对叶节点是对应采购边界，未把接缝、标识重复列为物料，也未将总成和其中器件重复计价。
2. 每个叶节点均有正确的模型映射；分别检查目录选择、模型选择、高亮、隐藏、透视、爆炸和收合。
3. 按所选部件核对右侧信息：功能、材质、尺寸、工艺等字段适用且准确；未知信息、参考做法与实物数据不混淆。
4. 对每个已显示的工艺图标检查点击、关闭、键盘操作和一句话内容；检查文本不遮挡或溢出。
5. 在桌面及移动端检查信息可读性、滚动与触控；在支持 WebGL 的环境验收真实模型效果。

## 六、从部件作用推导关键信息

先问这个部件与谁接触、承受什么、完成什么任务，再选择影响这些任务的参数；功能、体验与规格建立对应关系。信息应服务于理解和决策，不为了字段整齐罗列无关参数。已确认事实、设计要求与行业参考要分开。

| 部件或模块 | 作用与使用情境 | 优先展示的信息 |
| --- | --- | --- |
| 前壳 | 保护内部器件，与手机贴合并被经常触摸 | 功能、外观、材质、尺寸、成型及表面工艺；设计时关注防滑、耐磨、手机表面保护和无线充电兼容 |
| 后壳 | 保护内部器件并形成手持面 | 功能、外观、材质、尺寸、工艺；必要时关注手感和耐磨 |
| 中框 | 支撑机身、连接面盖及承受外力 | 功能、材质、尺寸、工艺；必要时关注强度、重量及装配配合 |
| USB-C 接口 | 与充电器或被充设备建立电连接，承载电力和连接、协议控制信号 | 功能、接口类型与数量、整机支持的输入和输出电压电流、协议；必要时关注插拔寿命与安装方式 |
| 电量与状态指示灯 | 让用户了解剩余电量及设备工作状态 | 显示内容、数量、颜色及灯效；开关、充电、异常等状态按实际证据分别说明，不因灯灭就推断整机关闭 |
| 按键 | 让用户触发查看电量、启动或关闭等操作 | 功能与操作方式；必要时关注位置、按压手感、尺寸与寿命 |
| 电芯与电池组件 | 储存并释放能量 | 类型、数量、容量、电压、能量、型号与温度监测；有条件时补充尺寸和安全参数 |
| 磁铁组件 | 吸附设备并辅助线圈对位 | 功能、磁体材料、排列与吸附力；未知参数标注未披露 |
| 无线线圈 | 发射交变磁场以传递能量 | 功能、材料、尺寸、电感及整机支持的无线功率；不能把整机功率当成线圈单独额定值 |
| PCBA 与电路功能 | 控制充放电、无线传输和保护 | 功能、关键控制器或保护器件、尺寸，以及与供电相关的输入输出能力 |

前壳接触手机并不意味着一定不能用金属；应结合无线传能与磁场、表面绝缘、防刮、重量等设计验证。光滑纹理可减少接触损伤风险，但防滑和防刮需结合材料与表面处理一起验证。USB-C 是接口形态，接口本身不决定功率；页面所列输入输出电压电流是整机在该接口上支持的规格。指示灯的具体开关状态定义，应以相应型号说明书或实测为准；如果只有电量和连接状态证据，就不能宣称存在单独的开关指示灯。
